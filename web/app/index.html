工作流状态由 engine 固定管理：待接 → 执行 → 门禁 → 审查 → 完成。它不再作为工单字段配置。

标签库

标签是工单唯一的自定义分类；ready-for-agent 是 engine 的派单开关，受保护。使用数实时从 beads 算，不另外存。

AI 预设

一份预设就是一组「执行器 + 模型 + 思考强度」。引擎只在流程节点上读它：执行和审查各选一份，互不影响。改预设对下一次运行生效；正在跑的工单用的是它开始时的快照。

读取预设中…

运行

整条流水线的运行参数。AI 用哪个执行器/模型由「AI 预设」决定，去「流程」里给执行、审查两个节点各选一份；通过后是否提交也在「流程 → 收尾」节点里。可派标签建议去「标签库」改名（会级联历史工单）；这里直接改只影响以后接单。

门禁

engine 每轮都按 执行 → 门禁 → 审查 跑它：返回 true 才进审查，{ pass: false, reason } 就把 reason 打回执行端继续改。默认 always true，改这个文件就能加测试/构建/自定义检查。

—

流程

点节点改它自己的提示词，并选一份 AI 预设（执行器 + 模型 + 思考强度）。执行和审查各选一份，互不影响。拓扑固定（接单 → 执行 → 门禁 → 审查 → 收尾），不能连线——改流程要改 engine。提示词存在项目的 .hlwd/prompts/，清空并保存 = 恢复工具自带模板。

打开项目

填一个本地目录的绝对路径。目录里没有 .hlwd/ 就自动建，并把配置与提示词写进去；没有 .beads/ 就顺手 bd init。
